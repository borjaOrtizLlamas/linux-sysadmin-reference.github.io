# 🐧 Linux SysAdmin Reference
 
A single-file interactive reference covering the most important Linux troubleshooting and administration commands, organized into five sections: **Network**, **CPU & Memory**, **Security**, **Storage**, and **Systemd**.
 
Each command card is expandable and includes practical examples with inline comments, difficulty badges (recommended / advanced / deprecated), and a direct link to the official documentation.
 
Built as a standalone HTML file — no dependencies, no internet required, works in any browser, and supports both light and dark mode automatically.
 
## Sections
 
| Section | Tabs |
|---|---|
| 🐧 Network Troubleshooting | Interfaces, Connectivity, DNS, Ports, Routes, Traffic, Firewall, Logs, VPN/Tunnels, Performance, Wi-Fi |
| 🖥️ CPU & Memory | CPU Overview, CPU Detail, Memory, Processes, Load & Scheduler, I/O & Disk, Profiling, Tuning |
| 🔒 Security & Hardening | Auditing, SSH, Access Control, Integrity, Intrusion, Kernel |
| 📦 Storage & Filesystems | Disk Usage, Block Devices, Filesystems, LVM, RAID, S.M.A.R.T. |
| 🔄 Services & Systemd | Services, Journal, Boot Analysis, Timers, Units & Deps, Targets & cgroups |
 
## Usage
 
Just open `index.html` in your browser — no setup needed.
